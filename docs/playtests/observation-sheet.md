# Arkusz obserwacji

Jeden arkusz na zespół. Wydrukuj albo skopiuj do notatek. Notuj **co widzisz i słyszysz**, nie
interpretuj. Dosłowne cytaty uczniów w cudzysłowie. Czas zapisuj z zegara gry albo stopera.

**Nie podpowiadaj.** Jeśli musisz pomóc (awaria, utknięcie > 2 min), zapisz to w sekcji F.

Zaznacz, jeśli wystąpiło:

- [ ] Nie wiedzą, że trzeba **przytrzymać** przycisk pracy.
- [ ] Niosą teczkę na stół bez żadnej pieczątki.
- [ ] Nie rozumieją kroku „Wybierz dowód” na stole.
- [ ] Mylą „Odrzuć” z „Z kontekstem”.
- [ ] Nie zauważają terminu teczki, aż przepada.
- [ ] Nie zauważają fioletowej podpowiedzi albo jej nie czytają.
- [ ] Zablokowane stanowisko po pomyłce — nie wiedzą, że można zabrać teczkę gdzie indziej.
- [ ] Redaktor prowadzący nie wie o przycisku „Przedłuż termin” (albo nie wie, po co jest).
- [ ] Nie używają sygnałów (Q / przycisk sygnału).
