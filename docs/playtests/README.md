# Playtest kit — Redakcja na Ostatnią Chwilę

Materiały do przeprowadzenia testu gry z klasą licealną w czasie jednej lekcji (45 min).
Pliki są po polsku, bo korzystają z nich nauczyciele, obserwatorzy i uczniowie.

| Plik | Dla kogo | Kiedy |
| --- | --- | --- |
| [`device-checklist.md`](device-checklist.md) | prowadzący, informatyk szkolny | dzień przed lekcją i 15 min przed |
| [`session-script.md`](session-script.md) | prowadzący | w trakcie lekcji, minuta po minucie |
| [`observation-sheet.md`](observation-sheet.md) | obserwatorzy (1 na 1–2 zespoły) | w trakcie gry, wydrukować |
| [`student-questionnaire.md`](student-questionnaire.md) | uczniowie | ostatnie 6 minut lekcji |
| [`results-log.md`](results-log.md) | zespół projektu | po lekcji, ten sam dzień |

Każdy test zapisujemy jako nową sekcję w `results-log.md` (albo kopię pliku
`results-log-RRRR-MM-DD.md` w tym katalogu) i przenosimy ustalenia do
`docs/implementation-plan.md` jako zadania lub notatki o balansie.
